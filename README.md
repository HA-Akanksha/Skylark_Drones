# Monday.com Business Intelligence Agent

## Overview
An AI-powered Business Intelligence dashboard that connects to Monday.com using GraphQL API and provides insights from Deals and Work Orders boards.

## Features
- Monday.com API Integration
- Dynamic Data Retrieval
- Deals Dashboard
- Work Orders Dashboard
- Business Insights
- Responsive Dashboard

## Technologies
- Python
- Flask
- HTML
- CSS
- Monday.com GraphQL API

## Installation

pip install -r requirements.txt

python app.py
